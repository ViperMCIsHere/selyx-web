Join in under a minute

Java Edition

  1. Open Minecraft 1.21 and choose Multiplayer.
  2. Select Add Server and paste play.selyxcraft.net
  3. Join, then type /rtp to start somewhere fresh.

Bedrock Edition

  1. Open Play, then the Servers tab.
  2. Select Add Server. Address play.selyxcraft.net, port 19132
  3. Join, then type /rtp to start somewhere fresh.
